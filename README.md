# Rent-a-Car System

This is a SaaS-based car rental system built using HTML, CSS, JavaScript, PHP, and a SQL database.

## Project Overview

This project aims to provide a fully functional car rental platform where users can browse and rent cars, and administrators can manage the fleet and rentals.

### Technologies

-   **Frontend:** HTML, CSS, JavaScript
-   **Backend:** PHP
-   **Database:** SQL (MySQL/MariaDB)

### Features (Planned)

-   User Registration and Login
-   Car Listings and Search
-   Rental Booking System
-   Admin Panel for Management
-   Payment Integration (Future)
